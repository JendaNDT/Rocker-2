# Zvuky vestavěných bicích

Obě sady vznikají z původních krátkých zvuků vytvořených generátorem v [MidiDrums.cpp](../../src/engine/MidiDrums.cpp). Kopák a tomy používají sinus s klesající výškou, virbl a činely přidávají šum s pevně daným počátečním stavem. Přehrávač připraví vzorky před začátkem hraní. Součástí sad jsou kopák, virbl, dva tomy, otevřená a zavřená hi-hat, crash a ride.
